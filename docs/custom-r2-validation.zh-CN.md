# CPM Custom r2 启动认证修复

版本：0.7.0+southflybird.2；标签：custom-v0.7.0-r2。

## 问题与修复

独立定制数据目录尚无本地账户，但进程继承了 CPM_API_KEY 时，认证探测返回 authenticated=false、user_auth_enabled=false。r1 仍挂载主页，主页请求 401 后清空会话并重新探测、再次挂载，形成连续闪烁和加载循环。

r2 在此场景显示 API 密钥验证页，验证成功后才挂载应用。单个资源的 403 会重新核验会话，不再清空并重建整个页面；并发认证探测合并为一次。存储被 WebView 禁用时，已验证密钥可在当前页面内存中使用。没有取消后端认证或清除系统环境变量。

## 已验证

- 35 项前端测试、ESLint、TypeScript 和静态构建通过。
- 桌面 UI 契约 26 项通过，原有 8 项已禁用自动替换功能用例继续跳过。
- 无密钥保护模式的真实 Edge UI 回归通过。
- 启用合成 API 密钥并禁用 localStorage：启动稳定显示验证页，不发送受保护请求；错误密钥不会进入应用；正确密钥恢复管理菜单及列表；撤销授权后停止保护数据轮询。
- 资源级 403 后的搜索、分页和勾选保持不变；自动刷新、临时网络失败、未保存编辑保留等回归通过。
- 12 项访问权限界面契约通过，包括配置授权撤销后即时移除对应列表数据；配置操作被拒绝时只重读可见配置，列表本身或可选分组请求被拒绝不会形成反馈循环。
- 使用真实冻结 EXE、临时数据库和合成密钥重复上述回归通过。
- 冻结恢复命令调度通过；r2 安装包和 SHA-256 已生成。

普通安装生命周期脚本检测到本机已有 CPM Custom 安装，按设计拒绝运行。本次没有通过卸载真实应用来绕过该检查；安装脚本未改动，r1 的隔离安装生命周期结果保留作参考。

## 安装与数据

关闭定制版后覆盖安装 r2。若出现密钥验证页，输入已有 CPM_API_KEY。若已经有本地账户，则继续使用账户登录。

定制版仍使用独立数据目录 `%LOCALAPPDATA%\CPM Custom`。原版账户和配置并未自动迁移；需要时应先备份，再导入副本。测试没有打开或修改原版数据库。
