## 部署和使用

1. 先更新 MyDrive，再更新 CPM。MyDrive 的 Wails 构建按仓库规定由用户运行。
2. CPM 设置 → 配置备份 → 整理备份与默认扩展数据：先扫描，再执行整理。
3. MyDrive 设置 → 备份 → 整理 CPM 封存包：保持解锁，先扫描再整理。
4. MyDrive 封存包、CPM 回收站原目录、CPM 旧备份分别由相应入口处理；
   不需要先解封真实账号。云端和历史完整备份不参与本次整理。
